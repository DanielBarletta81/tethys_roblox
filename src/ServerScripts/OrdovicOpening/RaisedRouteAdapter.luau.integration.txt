Integration into the existing Wildbound owner; permissions remain unchanged.

Install ../WildboundServer/Services/RaisedRouteAdapter.luau as the separate
ModuleScript WildboundServer.Services.RaisedRouteAdapter. In the existing
WildboundServer.WildboundBootstrap, after DeathExperience.Service.Start(), add:

require(servicesFolder:WaitForChild("RaisedRouteAdapter")).Start()

The adapter validates only the fixed CITY and WATCHER arrival markers, living
characters, stable dry footing, committed intake history and marker bounds.
It calls the existing RuntimeService and TitleService. It creates only the
server BindableFunction OrdovicOpening.BF_RouteProgress, using the same pattern
as the existing death-experience bridge. It grants no formal knowledge or Home.
